# SPK Hotel Kintamani MOORA - Backend

Backend untuk Sistem Pendukung Keputusan Pemilihan Hotel di Kintamani menggunakan metode MOORA.

## Tech Stack

- Go
- Gin
- MySQL
- Docker Compose
- JWT untuk tahap auth berikutnya
